# lobechat-17track-manifest

OpenAPI manifest hosting for the [17TRACK](https://www.17track.net/) LobeChat plugin.

- `lobe-chat/manifest.json` — OpenAPI 3.1 manifest describing the 11 Tracking API v2.4
  operations (https://asset.17track.net/api/document/v2.4_zh/index.html)

Served at:
https://raw.githubusercontent.com/electroluxcode/lobechat-17track-manifest/main/lobe-chat/manifest.json

The plugin entry lives in the [lobe-chat-plugins](https://github.com/lobehub/lobe-chat-plugins) index.
